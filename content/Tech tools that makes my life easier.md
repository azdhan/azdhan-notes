So it can be used to give it to an LLM for context purposes: https://r.jina.ai/YOUR_URL {for example -- https://r.jina.ai/https://www.cydir.com} - Read more [here](https://claude.ai/share/e2d3e4fe-c275-4413-992d-5c5db3faef4b)  the claude response on how to extract data on very customizable LLMs of our web website.
